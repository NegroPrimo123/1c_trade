# Учебный проект «Управление торговлей и складом» (1С:Предприятие 8.3)

Полноценная конфигурация 1С:Предприятие 8.3 в формате XML-исходников и скомпилированного контейнера `.cf`.

## Состав проекта

### 1. Перечисления (Enums)

- **СтатусыЗаказов**: `Новый`, `ВРаботе`, `Выполнен`, `Отменен`.
- **ТипыНоменклатуры**: `Товар`, `Услуга`.
- **ВидыОперацийДвиженияДенег**: `ОплатаОтПокупателя`, `ОплатаПоставщику`, `Прочее`.

### 2. Справочники (Catalogs)

- **Организации**: ИНН, Юридический адрес.
- **Контрагенты**: ИНН, КПП, Телефон, признаки «Покупатель» и «Поставщик».
- **Номенклатура**: Иерархический справочник (группы и элементы), Артикул, Единица измерения, Тип номенклатуры (ссылка на перечисление).
- **Склады**: Ответственный, Адрес.
- **СтатьиДвиженияДенег**: Описание статьи.

### 3. Регистры (все категории)

- **Регистры накопления (Accumulation Registers):**
  1. `ОстаткиТоваров` (Вид: **Остатки / Balance**):
     - Измерения: `Склад`, `Номенклатура`
     - Ресурсы: `Количество`
  2. `Продажи` (Вид: **Обороты / Turnovers**):
     - Измерения: `Номенклатура`, `Контрагент`
     - Ресурсы: `Количество`, `СуммаВыручки`, `Себестоимость`
  3. `ВзаиморасчетыСКонтрагентами` (Вид: **Остатки / Balance**):
     - Измерения: `Организация`, `Контрагент`
     - Ресурсы: `Сумма`
  4. `ДвиженияДенежныхСредств` (Вид: **Обороты / Turnovers**):
     - Измерения: `СтатьяДвижения`
     - Ресурсы: `Сумма`
- **Регистры сведений (Information Registers):**
  1. `ЦеныНоменклатуры` (Периодический: **В пределах дня / Day**, подчинен регистратору `ПриходнаяНакладная`):
     - Измерения: `Номенклатура`
     - Ресурсы: `Цена`
  2. `ШтрихкодыНоменклатуры` (Непериодический: **Независимый / Nonperiodical**):
     - Измерения: `Штрихкод`
     - Ресурсы: `Номенклатура`

### 4. Документы (Documents) с движениями (BSL `ОбработкаПроведения`)

- **ПриходнаяНакладная** (Поступление товаров):
  - Табличная часть `Товары` (Номенклатура, Количество, Цена, Сумма).
  - Формирует движения:
    - Приход в регистр накопления `ОстаткиТоваров`
    - Приход долга перед поставщиком в регистр `ВзаиморасчетыСКонтрагентами`
    - Запись среза цен в регистр сведений `ЦеныНоменклатуры`
- **РасходнаяНакладная** (Реализация товаров покупателю):
  - Табличная часть `Товары` (Номенклатура, Количество, Цена, Сумма, Себестоимость).
  - Формирует движения:
    - Расход со склада в регистре `ОстаткиТоваров`
    - Фиксация выручки и себестоимости в оборотном регистре `Продажи`
    - Возникновение задолженности покупателя в регистре `ВзаиморасчетыСКонтрагентами`
- **ПоступлениеДенег** (Оплата от покупателя):
  - Реквизиты: Организация, Контрагент, Статья движения, Вид операции, Сумма документа.
  - Формирует движения:
    - Приход в оборотный регистр `ДвиженияДенежныхСредств`
    - Погашение долга покупателя в регистре `ВзаиморасчетыСКонтрагентами`

### 5. Отчеты на СКД (Data Composition System)

- **ОстаткиТоваровНаСкладах**: группировка Склад -> Номенклатура, итоговый остаток.
- **ВаловаяПрибыль**: продажи по покупателям и номенклатуре с расчетом валовой прибыли (`Выручка - Себестоимость`).
- **ВзаиморасчетыСПокупателями**: ведомость расчетов (Долг на начало, Отгрузка, Оплата, Долг на конец).

### 6. Подсистема

- **ТорговляИУчет**: командный интерфейс Такси объединяет все справочники, документы, регистры и отчеты.

## Как загрузить проект в 1С:Предприятие 8.3

### Вариант 1 (Быстрый — через скомпилированный `.cf`):

1. Откройте **Конфигуратор** (пустая база или создайте новую).
2. Меню: **Конфигурация** → **Загрузить конфигурацию из файла...**
3. Выберите файл `C:\Users\makxim\Desktop\1c_trade\1c_trade.cf`.
4. На вопрос об обновлении базы данных нажмите **Да**.
5. В окне «Реорганизация информации» со списком таблиц нажмите **Принять**.
6. Нажмите **F5** для запуска в пользовательском режиме.

### Вариант 2 (Через XML-исходники):

1. Откройте **Конфигуратор**.
2. Меню: **Конфигурация** → **Загрузить конфигурацию из файлов...**
3. Выберите каталог: `C:\Users\makxim\Desktop\1c_trade\src\cf`.
4. Нажмите **F7** (_Обновить конфигурацию базы данных_) и подтвердите принятие изменений.
5. Нажмите **F5** для запуска.
